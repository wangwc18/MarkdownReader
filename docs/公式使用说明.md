# 公式与 physics

普通公式使用 `$x^2+1$`，独立公式使用单独两行的 `$$` 包围TeX原文。编辑菜单 → 数学工具 → 刷新所有数学公式可重新建立预览。

公式预览与HTML/SVG导出统一使用随包本地MathJax 3.1.2。需要physics命令时，打开偏好设置 → Markdown，勾选“启用 physics 包”并保存；例如 `$\dv{f}{x}$`、`$\pdv{f}{x}$`。在源码模式保存设置后，切换即时渲染即可看到结果。无需联网下载扩展。

开关同时应用于编辑预览、HTML和无样式HTML中的SVG公式。关闭开关会恢复普通预览，physics专用导数命令可能显示未知命令；原始Markdown不会因开关自动改写。

“支持使用双反斜杠和 \newline 换行”默认开启。开启时原始 `a\\b`、`c\newline d` 在行内及独立公式中分行；关闭时恢复MathJax标准处理。已有aligned等环境及显式displaylines保留其原有分行。兼容包装只用于渲染输入，不改写Markdown或保存内容；预览和HTML/SVG导出共用开关。

偏好设置 → Markdown → “自动添加公式序号”默认关闭。开启后，独立公式依次编号，支持手动 `\tag{X}`、`\notag`、align 多行和 `\label` / `\ref` / `\eqref`。编辑、删除、撤销、模式切换和 HTML 导出时重新建立当前文档的编号与引用；示例《公式编号验证.md》用于固定样本验收。

“当复制或导出为无格式 HTML 时”可选 SVG（默认）或 LaTeX 代码。LaTeX 选项保留行内 `$...$`，独立公式输出 `$$` 包围的原始 TeX，不包含预计算编号。该选项作用于无样式 HTML 和“复制为 HTML 代码”；编辑预览及普通带样式 HTML 继续使用 SVG。HTML 代码复制有选区时使用选区，无选区时使用全文。

复杂TeX环境、宏定义、重复标签、全部physics命令、完整选区复制与排版对齐尚未验收。示例《公式扩展验证.md》包含后续验收内容，不能据其存在认为所有项目已支持。
