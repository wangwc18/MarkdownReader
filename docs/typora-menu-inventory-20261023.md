## 现场保护

2026-10-24 补充：最大化自建测试窗口后成功展开“当插入本地图片时”，内部为“复制图片到文件夹…”及“上传图片”。前者要求文档已保存，选择目录会写入相对文档路径的 `typora-copy-images-to` YAML。详见图片插入目录规则.md、typora-image-insert-rules-tree.txt。工作区已补复制目录入口；上传仍缺失。本表其余早期差异需结合较新的专项记录判断，不能当作当前所有实现的快照。

首次菜单操作返回“user input was detected”，重新获取状态后继续。其后样本窗口出现未保存标记；在确认原因前没有保存、撤销或关闭该窗口，也未用磁盘内容替换缓冲区。磁盘《公式编号验证.md》的SHA256仍为 `1D8D1BE42338EE17A240BBF0A81AA98F931744C5FC5750C2BFE30A39A8F77ACB`。不能据磁盘未变声称窗口缓冲区也未变。

列表快捷键检查末项仅验证Ctrl+Shift+]没有误走缩进路径；观察到现有源码无序列表命令会在已有标记前再插入标记。这不证明列表切换行为对齐，后续须按原生列表样本比较并修正。
