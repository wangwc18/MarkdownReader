# 美式/英式英语与文档语言选择

后续已补双词典阻断网络重载，并发现本机原生UK选择的词语处理与产品不同，详见 [英语地区拼写对照补充.md](英语地区拼写对照补充.md)。下文“本轮没有”保留为首次实现轮次的范围记录。

工作区新增 dictionary-en-gb 3.0.0（MIT AND BSD），许可原文在 licenses/BritishDictionary-LICENSE.txt，构建脚本自动复制；和既有美式英语词典一样以本地延迟加载资源内嵌 EXE。依赖锁定在 package-lock.json。词典来源为 https://github.com/wooorm/dictionaries/tree/main/dictionaries/en-gb 。

编辑 → 拼写检查…现在打开当前文档语言选择，可选使用默认设置、不使用拼写检查、English (US)、English (UK)。偏好设置 → 编辑器提供默认启用开关和默认语言。显式文档语言覆盖全局默认及其开关；文档“不使用”始终关闭；“使用默认”跟随默认变化。个人词在两种英语中共用，仍按当前精确大小写规则认可。

全局默认保存于便携配置。文档语言作为当前打开文档的元数据，不写入 Markdown、不改变 dirty/revision，也不进入文本撤销历史。当前关闭并重新打开文件时不持久化文档覆盖选择；该行为尚未与 Typora 的跨会话规则对齐，不能称为完整每文档语言功能。语言切换按各自缓存异步加载词典，过时加载回调重新按当前文档解析，防止旧词典覆盖新选择。
