# 导出暂存目录验证

2026-10-19：Pandoc 导出的资源和输出改为置于系统临时目录中的独立暂存目录。暂存目录必须位于程序、文档和输出目录之外；临时目录配置不满足条件时返回错误。

使用 Go 1.26 的 os.Root 句柄约束文件访问。创建时记录父目录与根目录身份，消费输出和清理时复查；遍历拒绝符号链接、目录联接、其他重解析点和非普通文件。清理逐项调用 rooted Remove，不对转换器控制的目录递归调用 RemoveAll。检查或清理失败时保留剩余暂存内容并返回路径，调用方不替换既有输出。

export_stage_test.go 的三个测试覆盖中文普通目录清理、真实子进程生成 Windows junction、根目录被替换成 junction。后两项确认外部哨兵文件不变、异常目录保留；测试结束仅解除自建链接，再恢复并清理自建目录。未使用管理员符号链接权限，测试未跳过。

上述“清理失败不替换既有输出”描述 Pandoc 单文件导出路径。后来接入的文件夹输出先验证暂存内容，再备份并合并目标文件；提交完成后的清理失败会报错，但不撤销已成功提交的输出。详见 自定义导出.md 的文件夹输出说明。

这项处理约束的是 MarkdownReader 对暂存内容的读取和清理，不是任意转换程序的进程沙箱。文件夹模式已实现并通过选定样本，异常终止自动恢复、并发修改的全部组合及完整 Typora 对比仍未验收，不能依据本项测试认定全部自定义导出已完成。
