# 图片缩放

在即时渲染模式点击图片，选择“格式 → 图像 → 缩放图片”，可选 25%、33%、50%、67%、80%、100%、150%、200%。源码模式下格式菜单禁用，与已观察的 Typora 行为一致。

非 100% 的 Markdown 图片转换为带 `style="zoom:50%;"` 等样式的 HTML 图片。原始 Markdown 图片直接选择 100% 保持原文；HTML 图片恢复 100% 时移除 zoom，仍保留 HTML。重复缩放保留图片地址、替代文字、标题及其他属性。引用式图片只替换所选出现位置，不修改共享引用定义。
