# 图片根目录

即时渲染模式下选择“格式 → 图像 → 设置图片根目录…”，选择一个目录。程序在当前文档 YAML 前言内设置 `typora-root-url`，文档随后可正常保存、撤销及重做。原始图片引用保持不变；文档未保存时也可用绝对根目录加载图片。

示例：

```yaml
---
title: 图片示例
typora-root-url: C:\图片目录
---
```

该文档的 `![图](/assets/a.png)` 和 `![图](assets/a.png)` 都从 `C:\图片目录\assets\a.png` 加载。驱动器绝对路径、UNC 和 file URI 图片使用自身位置。根目录属于当前文档，不写入全局偏好。相对 YAML 根目录按文档所在目录解析，需要已保存文档；这一扩展路径规则已有后端测试，但尚未完成原生 Typora 对照。
