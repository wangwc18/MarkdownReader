# Typora 1.3.8 链接与图片基线

2026-10-16，通过 computer-use 在 `功能示例.md` 的末尾链接内打开格式菜单，并查看图像子菜单。

- 超链接：Ctrl+K；链接内有选中标记。
- 链接操作：打开链接、复制链接地址。无链接上下文时禁用。
- 图像：插入图片（Ctrl+Shift+I）、插入本地图片。
- 单图片操作：打开图片位置、拷贝图片、缩放图片、删除图片文件、复制图片到、移动图片到、上传图片。未选图片时禁用。
- 所有图片操作：复制所有图片到、移动所有图片到、上传所有本地图片、重新加载所有图片。
- 设置：当插入本地图片时、设置图片根目录、全局图像设置。

MarkdownReader 已实现链接打开/复制/编辑/移除、URL 图片插入/编辑、定位本地图片和重新加载图片。后续补充图片剪贴板粘贴、位图拷贝，PNG 样本已通过实际系统剪贴板往返与像素检查，详见验证报告。完整对齐尚未通过；Ctrl+K 对现有链接的精确切换行为、HTML/autolink/内嵌图片链接、缩放、所有图像格式、文件复制移动删除、根目录和上传服务仍待比较与实现。新增编辑与移除入口属于补充功能，不能视为 Typora 原菜单的逐项等同。
