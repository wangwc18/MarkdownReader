# 0.1.0 Preview 状态

本次首版整理以已经完成运行验证的编辑、文件、导出和随包英语拼写功能为基础。未完成运行验证的 Windows 系统拼写适配隔离出首版源码，仍使用随包词典；历史实验在本地归档保留。

## 可用范围

即时渲染与源码编辑、多文档管理、查找替换、表格、图片处理、公式与图表、常见导出格式及基础英文个人词典均已有实现和阶段验证。美式/英式词典可选择，当前文档可覆盖默认设置。

## 已知限制

- 不保证与 Typora 完全一致，暂不继续追求逐项行为对齐。
- 拼写建议、语言自动检测、其他语言及个人词典管理仍不完整；文档语言覆盖目前只在本次打开期间保留。
- 复杂 Markdown、组合选区、部分主题和高级导出设置仍有差异。
- 上传协议已做本地联调，真实第三方上传服务尚未全面验证。
- 干净 Windows 10/11、整机断网、无系统 WebView2 和普通用户环境尚未完成完整验收。

当前 GitHub 首版以源码可构建和基本功能稳定为目标。便携包为预览版，建议先使用文档副本体验。
