# MarkdownReader 0.1.0 Preview 2（2026-10-25）

本次更新整理后端目录与 Go 测试位置，并为文档标签增加 `×` 关闭按钮（快捷键 `Ctrl+W`）。已通过 Go 全套测试、go vet、前端 77 项测试和生产构建；实际启动验证了桌面桥接和标签关闭。

这是功能对齐中的阶段交付，完整 Typora 1.3.8 文档功能尚未验收完成。解压到可写目录，运行 MarkdownReader.exe。程序旁 data 保存配置、恢复数据和本地诊断；目录不可写时需更换解压位置。

本次首版整理纳入图片复制/移动、插入规则、上传协议适配、渲染智能标点、随包美式/英式英语词典及基础个人词典。未完成运行验证的系统拼写实验未纳入。当前范围与基础检查见 docs/STATUS.md；历史记录描述的是各自开发阶段，不代表本版已完成全部对齐。

包含 x64 WebView2 固定运行时 155.0.4283.45、Pandoc 3.12.1、本地编辑器/公式/图表资源及许可证。无需开发工具即可尝试运行；这并不代表干净 Windows 10/11、断网、普通用户以及无系统 WebView2 的环境测试已经通过。

已确认工具执行环境可能在启动命令返回时终止后台进程；此前全部异常退出尚未逐一归因。预览仍需验证稳定性，不将已有测试次数当作无故障保证。

自动上传完整行为、多语言拼写、个人词典管理、复杂语法/选区/主题、全部原生导出选项等仍有差异。当前英文建议词与 Typora 也有差别。真实上传服务尚未完整验证。请用副本试用当前阶段版本。
