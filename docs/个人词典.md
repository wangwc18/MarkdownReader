# 便携个人词典：添加英文词

渲染区错词右键菜单增加“添加到字典”，入口依据本机 Typora 1.3.8 已观察的菜单。点击后不修改 Markdown，认可同一英文词在正文和行内代码中的出现。词条存入程序目录 data/settings.json 的 personalWords 映射；程序重启后仍生效，随便携目录一起移动。当前没有修改系统或 Typora 的词典。

后端 AddPersonalWord 校验英文单词及内部撇号，弯撇号统一为直撇号；最多64字符、10000个词。保存沿用共享磁盘锁和原子替换，词映射逐键合并，避免不同窗口新增词时覆盖彼此。返回设置为独立副本。保存失败恢复内存状态，并保留原配置文件。

前端认可词与基础 nspell 词典分离，不永久修改内嵌词库或其缓存。当前精确匹配大小写，不将个人词加入建议候选；这些行为尚未与 Typora 完整比较。词典管理、移除、忽略、其他语言以及源码模式仍未完成。

## 验证

- 前端75项、Go/脚本测试、go vet、生产构建通过。新增后端案例验证独立实例基于旧快照添加不同词后两词均保留、去重、第三实例重载、快照隔离、非法输入、撇号规范化以及损坏配置时拒绝写入并回滚内存。
- personal-word-result.json 的5项：实际 computer-use 右键正文 quikc 并点击“添加到字典”，确认持久化、正文和行内两处标记清除、源码和 dirty 不变、模式往返保持、重复添加不增项。
- 正常退出后启动不同 EXE 进程，personal-word-restart-result.json 的3项确认磁盘词条加载、无错词标记、原始源码未变。computer-use 直接查看重启窗口，两处均无红线。
- 两轮预持有进程句柄均记录 exitCode=0：personal-word-held-result.json、personal-word-restart-held-result.json。personal-word-restore-result.json 确认测试前词映射与拼写开关均恢复，未遗留测试词。

这轮没有在 Typora 中执行添加，因为这会改变其用户词典；只使用此前已观察入口作为基线。上述证据证明产品固定英文样本的添加/持久化链路，不证明完整原生个人词典行为、跨操作系统环境或便携 ZIP 验收。旧便携预览包未更新。
