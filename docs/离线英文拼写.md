# 离线美式英语拼写阶段实现

后续已加入基础英文个人词典，详见 [个人词典.md](个人词典.md)；下文原轮次的缺项以该专项最新记录补充。

后续又加入英式英语和当前文档语言选择，详见 [英语拼写语言选择.md](英语拼写语言选择.md)；自动检测及完整语言覆盖仍未完成。

使用锁定的 nspell 2.1.5（MIT）、dictionary-en 4.0.0（MIT AND BSD，美式英语词表）及其 is-buffer 2.0.5（MIT）依赖。完整许可分别保存在 licenses/Nspell-LICENSE.txt、EnglishDictionary-LICENSE.txt、IsBuffer-LICENSE.txt；prepare-assets.ps1 在干净构建时重新复制。词典 aff/dic 通过 Vite raw import 编入本地延迟加载资源，并嵌入 EXE，不运行时下载词典。API 依据为 https://github.com/wooorm/nspell ，词典来源为 https://github.com/wooorm/dictionaries/tree/main/dictionaries/en 。

开启现有拼写开关后，美式英语错词使用 CSS Custom Highlight 红色波浪线标记。它不插入文本节点或 Markdown 标记。正文和行内代码参与，围栏代码排除，与原生固定样本的范围一致。公式、编辑器标记和预览等暂时排除，完整原生范围未验收。当前只识别英文单词及直/弯撇号，不代表多语言自动检测已实现。

渲染区右键错词出现美式英语建议菜单。替换前将选区映射回原始 Markdown，核对词文本并保存文档身份/正文快照；点击建议时再次核对，文档已变化则拒绝应用旧范围。替换使用现有编辑与历史路径。过长词不计算建议，避免组合爆炸；大文档性能仍待专门验收。

## 验证

- 前端 74 项（含真实词典对 quikc/quick、color/colour、Unicode 偏移与撇号），Go/脚本测试、go vet、生产构建通过。
- offline-spell-result.json 共 9 项：禁用缓存并重载实际应用，外部 HTTP(S) 请求被 CDP 拦截，实际加载 16 个本地请求，测试探针确被阻断；内嵌词典标记正文和行内两个 quikc，围栏代码无标记，源文档/dirty 不变，DOM 菜单事件能建议 quick、替换精确、撤销重做精确、关闭清除标记。
- computer-use 直接观察到两个错词红线，真实右键正文并点击 quick。offline-spell-native-result.json 的 4 项检查随后确认实际操作的精确源码、撤销、重做和保存关闭后的新后端读取。该轮程序正常退出，预持有句柄记录 exitCode=0（offline-spell-held-result.json）。测试设置已恢复。

这次阻断验证仅覆盖应用页面外部 HTTP 请求，不是关闭 Windows 网络，也不能替代干净 Win10/11、无系统 WebView2、普通权限和整包断网启动验收。

## 仍有差异

Typora 对原生样本建议 quick、quack，并提供添加到字典；本词典目前仅建议 quick，基础英文添加已补充，管理和完整规则仍有差异。语言选择、自动检测、每文档和默认语言关系、多语言词典、忽略、源码模式、复杂跨节点词语、完整键盘菜单操作及性能仍未完成。不能把单个英文样本的离线工作链路称为完整拼写对齐。新 EXE 仅位于 build/bin/MarkdownReader.exe，便携预览 ZIP 未更新。
