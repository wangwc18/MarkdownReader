# 全局图片复制预设和指定路径

按本机 Typora 1.3.8 已实际展开的选项（typora-image-insertion-options-tree.txt），图像偏好现提供：无特殊操作、复制到当前文件夹（./）、复制到 ./assets、复制到 ./${filename}.assets、上传图片、复制到指定路径。

三种预设保存为现有复制动作和对应目录；指定路径单独保存 imageFolderCustom=true，并显示目录输入与原生“选择图片目录…”按钮。预设模式隐藏自定义路径控件；重开偏好按已保存模式与目录选回正确项目。选择框只填入表单，点击偏好“保存”后才持久化。

明确选择指定路径后支持完整绝对路径、上级相对路径和现有 ${filename} 展开。路径按操作系统目录语义创建并解析，沿用图片写入的重名保护。缺少明确自定义标志的旧配置继续沿用文档内相对目录限制；不把旧的非法绝对/上级路径悄悄启用为写入目标。盘符相对路径 C:relative 被拒绝。
