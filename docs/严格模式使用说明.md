# 严格与宽松模式

在“偏好设置 → Markdown”中勾选或取消“严格模式”，保存后立即应用于即时渲染和 HTML 导出。

严格模式要求 ATX 标题的 # 后有空白，列表续行按列表标记宽度缩进。宽松模式允许缺少空白的标题，以及两列最小缩进的列表续行和子列表。代码块、行内代码和转义文字仍按字面显示。新配置与旧版本配置默认使用严格模式。

切换解析模式不主动改写 Markdown。即时渲染编辑使用序列化基线映射实际变化，避免把编辑器原本的标题空格、列表编号或缩进规范化写回未编辑部分。所测样本通过了原文逐字符保留、撤销、保存并重新读取磁盘的验证。

当前为固定样本已验证的实现。全部复杂 GFM 容器、列表和空白组合、中文输入组合及各格式导出仍需继续对齐；原生对照与证据见 strict-mode-research.md。
