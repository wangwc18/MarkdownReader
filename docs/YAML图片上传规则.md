# 文档 YAML 图片上传规则

`typora-copy-images-to: upload` 现在被识别为上传操作，不再当作名为 upload 的目录。显式 `./upload` 仍是复制目录。图像偏好新增“允许根据 YAML 设置自动上传图片”，默认关闭；关闭时继续使用原来的本地插入/剪贴板存储规则，不自动调用上传器。

开启后，“插入本地图片”和剪贴板图片使用已配置的 Custom Command、PicGo-Core 或 PicGo app 服务。菜单“格式→图像→当插入本地图片时→上传图片”写入 YAML，并通过现有文档历史支持撤销重做。后端在运行上传器期间释放文档锁，返回前再次核对文档内容与路径；外部上传已经发生时无法撤回，文档变化则返回明确错误而不插入地址。

剪贴板上传使用程序数据目录中的专用临时文件，成功、失败均尝试清理。不允许上传器返回该临时目录内部的 file 地址，避免清理后将失效地址写入正文。普通持久 file 地址及 HTTP/HTTPS 地址沿用上传协议。上传失败保留原正文与本地源，可在偏好设置查看上次输出。
