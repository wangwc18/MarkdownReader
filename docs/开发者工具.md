# 开发者工具

选择“视图 → 开发者工具”，或在主编辑窗口按 Shift+F12，打开当前页面的WebView2检查器。重复打开会使用检查器自身的窗口处理，关闭检查器后可以继续编辑文档。程序使用随包WebView2提供的工具，不需要安装浏览器或开发环境。

## 本轮验证（2026-10-23）

- 本机Typora菜单基线为“开发者工具 Shift+F12”，见typora-view-menu-tree.txt。本轮没有操作原生Typora检查器内部，不宣称两个不同浏览器内核的全部调试工具相同。
- MarkdownReader生产构建原生调用及重复调用成功。computer-use实际观察DevTools - wails.localhost/，关闭后在主窗口按Shift+F12，观察新检查器窗口并关闭；之后又实际点击视图菜单入口，确认创建检查器窗口。
- devtools-smoke-result.json 5项检查通过，包括菜单标签、原生成功响应、重复调用、文档/历史保持。测试文档清理后主编辑器正常；一次后台观察等待时间较长，保持原会话继续观察，主窗口激活后完成，没有因观察延迟重启测试。
- 原始菜单和检查器结构见devtools-native-menu-tree.txt、devtools-native-window-tree.txt。
- 本地WebView2补丁在UI/COM线程处理请求，校验顶层及发送方来源；本包测试通过。主程序/脚本包Go测试、go vet及生产构建通过，前端58项通过。
- 补丁后的受控离线渲染/PDF10项、公式5项回归通过，分别25和14个本地请求，只有刻意网络探针被阻断。此检查不等于干净Windows10/11环境验收，也不验证检查器所有面板及其在线文档链接。
