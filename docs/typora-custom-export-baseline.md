# Typora 1.3.8 自定义导出基线

2026-10-19，通过 computer-use 检查本机 Typora 偏好设置 → 导出 → 添加 → 自定义。

新增了一个名为“MarkdownReader 对比测试”的空白导出配置，供继续对比使用。命令字段保持空白，未运行任何命令；原有导出项未改名、删除或重排。该测试项仍保留在本机 Typora 中。

实际观察到：

| 项目 | 控件与行为 | MarkdownReader 状态 |
|---|---|---|
| 命令 | 单个文本输入框，另有官方帮助链接 | 目前为程序路径 + 每行独立参数；单字段命令仍有差异 |
| 路径方式 | 不选择导出路径、选择导出的文件位置、选择导出的文件夹位置 | 三种均已实现，另有标准输出写文件选项 |
| 无输出默认 | 新增自定义模板默认“不选择导出路径” | MarkdownReader 新建程序项默认文件输出，仍有默认值差异 |
| 导出后 | 显示命令行输出 | 已实现，包含日志编码选择 |
| 文件夹方式 | 选中后额外显示“打开导出文件所在目录” | 已实现逐项打开/不打开，另支持继承全局设置；已实际验证打开输出目录本身。精确 UI 及其他格式仍待完整比较 |

首次通过 UIA 列表项目点击没有改变路径方式；改用展开列表后的屏幕坐标点击，截图确认变成“选择导出的文件夹位置”。本次只证明上述设置入口及可见选项，不证明命令执行、文件夹覆盖、变量或错误处理与 Typora 完全相同。
