# Typora 1.3.8 表格基线

2026-10-16，使用 computer-use 在本机 Typora 打开 `examples/功能示例.md`，点击“即时渲染”单元格后检查。

| 入口 | 命令 | 快捷键 / 实测 |
|---|---|---|
| 段落 → 表格 | 插入表格 | Ctrl+T；在现有表格内禁用 |
| 同上 | 上方插入行 | 实测在当前数据行之前增加空行，光标进入新行；随后撤销恢复 |
| 同上 | 下方插入行 | Ctrl+Enter |
| 同上 | 左侧插入列、右侧插入列 | 菜单已读 |
| 同上 | 上移该行、下移该行 | Alt+↑ / Alt+↓；第一条数据行可与表头交换，已实测后撤销 |
| 同上 | 左移该列、右移该列 | Alt+← / Alt+→ |
| 同上 | 删除行 | Ctrl+Shift+Backspace |
| 同上 | 删除列、复制表格、格式化表格源码、删除表格 | 菜单已读；删除命令未在 Typora 实测 |
| 单元格激活后的工具条 | 调整表格、左/居中/右对齐、更多操作、删除表格 | 已观察 |
| 表格内键盘 | Tab / Shift+Tab | 普通格跳到下一/上一格并选中文字；最后一格 Tab 增加空行；表头第一格 Shift+Tab 在表头下增加空行，光标进入首列。已实际操作后撤销恢复 |

MarkdownReader 已实现上述基础命令，并有源文与实际应用结构回归。完整交互对齐仍未证明：多单元格选区、单元格内换行、嵌套列表表格、拖动调整、缩减行列及表头边界的所有细节仍需逐项比较。工具条位置及样式与 Typora 存在差异。
