# Typora 1.3.8 公式换行对比（2026-10-23）

computer-use在独立测试文档输入行内、独立双反斜杠、newline、aligned和displaylines五种案例，原文保存到build/test-tools/typora-math-lines-native-20261023.md。发布样本为examples/公式换行验证.md，增加标题，公式正文相同。

| 公式内容 | 开启兼容换行 | 关闭并真正重启后 |
| --- | --- | --- |
| 行内 `a\\b` | a和b上下两行 | 同行ab |
| 独立 `a\\b` | 两行 | 同行ab |
| 独立 `c\newline d` | 两行 | 同行cd |
| `\begin{aligned}x&=y\\z&=w\end{aligned}` | 两行对齐 | 保持两行对齐 |
| `\displaylines{m\\n}` | 两行 | 保持两行 |

原设置开启。临时关闭后，第一次Ctrl+Q未真正退出；受限终端的Get-Process漏报沙箱外进程，不能作为退出证据。随后通过完整进程视图发现仍在运行，逐个正常关闭三个已保存测试窗口，完整进程核对Count=0后启动新窗口，重新打开保存的相同文件，取得上表关闭状态。该次关闭状态的偏好页也确认复选框未勾选。

结束时重新勾选开启，截图确认，正常关闭窗口及程序自带“不是现在”提示，完整进程核验Count=0，再启动空白Typora窗口。未修改许可证机制、用户文档或其他偏好。为文件关联排查新开的资源管理器窗口后来处于最小化状态，没有继续控制用户当前窗口。

MarkdownReader的mathLineBreaks默认开启，旧配置缺少字段也开启，显式关闭可持久化。渲染预过滤器只包装无现成多行环境的TeX，data-math与原始Markdown保持不变。已有环境保持原样；复杂嵌套、宏和全部TeX语法尚待继续比较。
