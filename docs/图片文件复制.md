# 复制图片到文件

在即时渲染模式点击本地、内嵌 data URI 或 HTTP/HTTPS 图片，选择“格式 → 图像 → 复制图片到…”。在原生保存对话框选择目标文件，副本生成后更新当前图片地址。Markdown 图片保留替代文字和标题；HTML 图片保留其他属性及缩放。共享引用图片会将所选出现位置转换为独立引用，其余图片和原引用定义保持不变。内嵌及网络图片的新增实现目前仅在工作区构建和源码包中，尚未更新便携 ZIP；网络固定样本与限制见网络图片单张复制.md。

带 `typora-root-url` 时，复制地址按图片根目录计算，包含原生观察到的 `/../` 写法。复制保留源文件字节，不重新编码。

撤销同时还原地址和目标文件状态：新副本会移除，覆盖的文件会恢复；重做重新生成副本。副本或目标位置被外部修改时拒绝撤销/重做，文档历史不前移，避免覆盖新内容。文件操作历史与其他编辑历史一样属于当前会话，关闭文档后清除。

### 内嵌图片追加验证（2026-10-24）

computer-use 检查 Typora 的 PNG data URI 单张复制：默认文件名为替代文字加 `.png`，导出 135 字节 PNG 与样本 SHA256 一致，见 typora-data-image-copy-tree.txt、typora-data-image-copy-hashes.json。该窗口之前设置过根目录，替换正文后仍保留内部根目录状态，因此输出地址不作为全新无根目录文档的依据。

MarkdownReader 的两个实际原生保存框均完成：Markdown 默认“内嵌.png”，HTML 默认“HTML.png”。data-image-native-result.json 的 9 项及 data-image-html-result.json 的 8 项通过，覆盖精确字节、Markdown 标题、HTML 的 alt/title/zoom 属性、相邻引用不变、分别撤销重做、保存后全新读取及重新打开渲染。另有 101 项相关桌面回归通过，记录在 data-copy-regression-*.json。

解码器支持固定图片 MIME 的 base64 和百分号编码，保持字节而不转码；支持格式的解析不等于所有格式都已与 Typora 逐项核对。后端测试覆盖 PNG、SVG、编码错误及 Windows 文件名处理。Typora 新窗口的内嵌图片批量复制仍显示 Copying，尚无完成结果，不能据此推断批量行为。

目前此入口处理本地及支持 MIME 的内嵌/网络图片，单个源文件/原目标快照限 20MB，会话图片快照合计限 128MB；这些限制尚未与 Typora 完整对齐。网络/内嵌图片批量复制、复杂认证网络、移动图片、不同盘符、重名覆盖的完整原生对照、任意扩展名及所有复杂语法仍待完成。批量本地复制的工作区实现和未发布原因见“批量图片复制.md”。覆盖恢复已通过后端样本，尚不能据此声称原生覆盖流程一致。
